## 一、需求概述

### 1.1 现状分析

PatWiki 当前 `CustomFieldType` 枚举包含 10 种类型（text/textarea/number/date/boolean/select/multi_select/url/rating/ai_field），**完全缺失公式字段类型**。飞书多维表格支持 50+ 函数的跨字段计算，是多维表格的灵魂功能。

### 1.2 目标

- 新增 `FORMULA` 字段类型
- 支持 30+ 常用函数（数学/文本/日期/逻辑/聚合）
- 支持 AST 安全解析，禁止危险函数调用
- 支持字段依赖图，自动计算顺序
- 支持增量更新（仅重算受影响字段）
- 支持跨自定义字段引用

### 1.3 专利场景示例

| 公式 | 说明 |
|------|------|
| `DATEDIFF(TODAY(), filing_date, "year")` | 专利年龄 |
| `IF(risk_level == "critical", "alert", IF(risk_level == "high", "warn", ""))` | 风险标识 |
| `CONCAT(applicant, " - ", title)` | 申请人+标题组合 |
| `IF(legal_status == "granted", "已授权", "未授权")` | 授权状态 |
| `DATEDIFF(TODAY(), grant_date, "year")` | 授权后年限 |

## 三、表达式引擎设计

### 3.1 架构

```
用户输入表达式 -> Lexer(词法分析) -> Parser(语法分析/AST) -> Validator(白名单校验) -> Evaluator(求值)
```

### 3.2 函数白名单（30+ 函数）

| 分类 | 函数 |
|------|------|
| 数学 | ABS, ROUND, FLOOR, CEIL, MAX, MIN, SUM, AVG, POWER, SQRT, LOG, LN |
| 文本 | CONCAT, LEN, UPPER, LOWER, TRIM, SUBSTRING, REPLACE, SPLIT, CONTAINS, STARTS_WITH, ENDS_WITH |
| 日期 | TODAY, NOW, YEAR, MONTH, DAY, DATEDIFF, DATEADD, WEEKDAY |
| 逻辑 | IF, AND, OR, NOT, IS_EMPTY, IS_NOT_EMPTY, COALESCE |
| 类型转换 | TEXT, NUMBER, BOOLEAN |

### 3.3 AST 解析器核心

```python
class FormulaEngine:
    BINOPS = {
        ast.Add: operator.add, ast.Sub: operator.sub,
        ast.Mult: operator.mul, ast.Div: operator.truediv,
        ast.Mod: operator.mod, ast.Pow: operator.pow
    }
    CMPOPS = {
        ast.Eq: operator.eq, ast.NotEq: operator.ne,
        ast.Lt: operator.lt, ast.LtE: operator.le,
        ast.Gt: operator.gt, ast.GtE: operator.ge
    }

    def parse(self, expression: str) -> ast.AST:
        tree = ast.parse(expression, mode="eval")
        self._validate_ast(tree)
        return tree

    def extract_dependencies(self, tree: ast.AST) -> set:
        return {node.id for node in ast.walk(tree) if isinstance(node, ast.Name)}

    def evaluate(self, tree: ast.AST, field_values: dict) -> Any:
        return self._eval_node(tree.body, field_values)
```
