## 一、需求概述

### 1.1 现状分析

PatWiki 当前**完全缺失数据导出功能**。对于以 Excel 为数据源的专利管理场景，无法导出是硬伤——用户导入数据后无法导回 Excel 进行二次处理或汇报。

### 1.2 目标

- 支持 Excel (.xlsx) 导出，保留格式和列宽
- 支持 CSV 导出（UTF-8 BOM，兼容 Excel 中文）
- 支持按视图筛选导出（仅导出当前视图可见数据）
- 支持字段选择（选择导出哪些列）
- 支持多 Sheet 导出（按分组/分类拆分 Sheet）

    )

@router.post("/export/csv")
async def export_csv(db, database_id, view_id=None, field_keys=None, filters=None):
    data = ExportService.export_to_csv(db, database_id, view_id, field_keys, filters)
    return StreamingResponse(
        io.BytesIO(data),
        media_type="text/csv",
        headers={"Content-Disposition": "attachment; filename=patents_export.csv"}
    )
