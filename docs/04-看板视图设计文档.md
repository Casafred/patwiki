---

## 一、需求概述

### 1.1 现状分析

PatWiki 当前仅有表格视图（`PatentView` 的 `view_type` 默认为 `personal`，实际渲染只有表格）。飞书多维表格有 6 种视图，看板视图是使用频率第二高的视图类型。

### 1.2 目标

- PatentView 新增 `view_type = "kanban"` 视图类型
- 按状态字段（如 legal_status / risk_level / application_status）分组
- 卡片展示专利摘要信息
- 支持拖拽改变分组状态
- 支持自定义分组列和卡片显示字段

### 2.1 PatentView 扩展

```python
class PatentView(Base):
    # view_type 已是 String(30)，直接扩展值
    # 新增看板配置
    kanban_config = Column(JSON, default=dict)
    # kanban_config 结构:
    # {
    #   "group_by_field": "legal_status",
    #   "group_values": ["pending", "granted", ...],
    #   "card_fields": ["application_number", "title", "applicant"],
    #   "card_title_field": "title",
    # }
```

### 2.2 视图类型枚举值

```
table      -> 表格视图（现有）
kanban     -> 看板视图（第一期）
form       -> 表单视图（第二期）
gantt      -> 甘特视图（第二期）
calendar   -> 日历视图（未来）
gallery    -> 画册视图（未来）
```

## 四、前端设计

### 4.1 KanbanView 组件

```
components/views/KanbanView.tsx
- 看板列容器（水平滚动）
  - 看板列（按分组值）
    - 列头（分组标签 + 计数）
    - 卡片列表（垂直滚动）
      - 专利卡片
        - 卡片标题（card_title_field）
        - 卡片字段列表（card_fields）
        - 拖拽手柄
  - 未分组列
- 看板配置面板（侧边栏）
  - 分组字段选择
  - 分组列排序
  - 卡片显示字段选择
- 拖拽交互（@dnd-kit/sortable）
```

### 4.2 拖拽实现

使用 `@dnd-kit/core` + `@dnd-kit/sortable`：
- 卡片可在列内排序
- 卡片可跨列拖拽（触发 `move_kanban_card`）
- 拖拽中显示半透明预览

### 4.3 PatentListPage 集成

```tsx
// PatentListPage.tsx 中根据 view.view_type 渲染不同组件
{view.view_type === "table" && <TableView ... />}
{view.view_type === "kanban" && <KanbanView ... />}
{view.view_type === "gantt" && <GanttView ... />}
{view.view_type === "form" && <FormView ... />}
```
