## 一、需求概述

### 1.1 现状分析

PatWiki 当前数据录入仅通过 Excel 导入和表格内联编辑，**无表单视图**。飞书多维表格的表单视图允许以表单方式逐条录入数据，适合移动端和现场录入场景。

### 1.2 目标

- PatentView 新增 `view_type = "form"` 视图类型
- 支持以表单方式逐条新增/编辑专利
- 支持字段排列、分组、条件显示
- 支持必填校验和默认值
- 支持表单分享链接（只读提交，无需打开完整应用）

### 1.3 专利场景示例

| 场景 | 说明 |
|------|------|
| 新专利录入 | 通过表单逐字段填写专利信息 |
| 现场补充信息 | 在评审会上通过表单补充风险等级、备注 |
| 外部提交 | 代理人通过分享链接提交专利信息 |

### 2.2 分享链接模型（新增）

```python
class FormShareLink(Base):
    __tablename__ = "form_share_links"
    id = Column(Integer, primary_key=True, index=True)
    view_id = Column(Integer, ForeignKey("patent_views.id"), nullable=False, index=True)
    token = Column(String(64), unique=True, nullable=False, index=True)
    is_active = Column(Boolean, default=True)
    expires_at = Column(DateTime, nullable=True)
    created_at = Column(DateTime, server_default=func.now())
```

## 五、集成点

1. PatentListPage 新增"表单视图"选项
2. 表单提交复用 `PatentService.create_patent` / `update_patent`
3. 表单提交后触发公式重算和自动化规则
4. 分享链接路由在 Tauri 应用中不可用（仅 Web 模式）

## 六、测试计划

| 测试项 | 预期结果 |
