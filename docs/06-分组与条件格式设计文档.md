## 一、需求概述

### 1.1 现状分析

PatWiki 的表格视图有 filter_config/column_config/sort_config，但**无分组功能和条件格式**。飞书多维表格支持按字段分组折叠展示，以及基于条件自动着色单元格。

### 1.2 目标

- 表格视图新增分组功能（group_by_config）
- 表格视图新增条件格式（conditional_formatting）
- 分组支持多级嵌套（最多 3 级）
- 条件格式支持字体颜色、背景色、图标

### 1.3 专利场景示例

| 功能 | 场景 |
|------|------|
| 按法律状态分组 | 授权/驳回/待审分组展示 |
| 按申请人分组 | 同一申请人的专利聚拢 |
| 风险等级着色 | critical=红底，high=橙底 |
| 授权到期提醒 | 30天内到期=黄字闪烁 |

### 3.2 条件运算符

CONDITION_OPERATORS = {
    "==": lambda a, b: a == b,
    "!=": lambda a, b: a != b,
    ">": lambda a, b: float(a) > float(b),
    "<": lambda a, b: float(a) < float(b),
    ">=": lambda a, b: float(a) >= float(b),
    "<=": lambda a, b: float(a) <= float(b),

## 五、前端设计

### 5.1 分组渲染

```
TableView.tsx 增强：
- 检测 group_by_config 是否为空
  - 非空：渲染分组表格
    - 分组头行（字段值 + 计数 + 折叠按钮）
    - 分组内数据行（缩进展示）
    - 多级分组嵌套（每级缩进 + 折叠）
  - 为空：渲染普通表格（现有）
- 分组折叠状态持久化到 view 配置
```

### 5.2 条件格式渲染

```tsx
// 在单元格渲染时应用条件格式
function getCellStyle(view, fieldKey, value) {
    const cf = view.conditional_formatting?.find(c => c.field === fieldKey);
    if (!cf) return {};
    const matched = cf.conditions.find(c => matchCondition(c, value));
    return matched?.style || {};
}

// TableCell 渲染
<td style={getCellStyle(view, field.key, cellValue)}>
    {cellValue}
</td>
```
