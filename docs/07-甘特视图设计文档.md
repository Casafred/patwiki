## 一、需求概述

### 1.1 现状分析

PatWiki 有 filing_date/grant_date 等日期字段，但**无甘特视图**展示专利时间线。飞书多维表格甘特视图适合项目管理和时间线可视化。

### 1.2 目标

- PatentView 新增 `view_type = "gantt"` 视图类型
- 支持指定开始日期字段和结束日期字段
- 支持时间轴缩放（日/周/月/季/年）
- 支持按字段分组甘特条
- 支持拖拽调整日期范围

### 1.3 专利场景示例

| 场景 | 开始字段 | 结束字段 |
|------|---------|---------|
| 申请到授权周期 | filing_date | grant_date |
| OA 答复期限 | oa_receive_date | oa_deadline |
| 年费缴纳窗口 | fee_start_date | fee_deadline |

## 四、前端设计

### 4.1 GanttView 组件

```
components/views/GanttView.tsx
- 左侧任务列表区
  - 分组标题
  - 任务行（title_field 值）
- 右侧时间轴区
  - 时间刻度（日/周/月/季/年）
  - 甘特条（按 start/end 定位）
  - 分组分隔线
  - 今日标记线
- 工具栏
  - 时间缩放切换
  - 跳转到今日
  - 配置按钮
- 拖拽交互
  - 拖拽甘特条整体移动（调整 start+end）
  - 拖拽左/右边缘（调整 start 或 end）
```

### 4.2 时间轴实现

使用 SVG 或 Canvas 渲染时间轴和甘特条：
- 计算每像素代表的时间单位
- 根据时间范围渲染刻度
- 甘特条按 start/end 计算位置和宽度

### 4.3 甘特条颜色

根据 `bar_color_field` 和 `bar_color_map` 动态着色。
