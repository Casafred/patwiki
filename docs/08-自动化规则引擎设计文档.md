> **差距项**: Should-Have #8 — 自动化规则引擎  
> **差距等级**: 增强（效率提升）  
> **实施期**: 第三期 W1  
> **预估工期**: 1.5 周

---

## 一、需求概述

### 1.1 现状分析

PatWiki 当前所有操作均为手动触发，**无自动化规则引擎**。飞书多维表格支持基于事件触发的自动化流程（如字段变更时通知、状态变更时更新关联记录）。

### 1.2 目标

- 支持基于事件驱动的自动化规则（Trigger → Condition → Action）
- 支持 5+ 触发器类型和 6+ 动作类型
- 支持规则执行日志和错误回退
- 支持规则的启用/禁用和执行顺序

### 1.3 专利场景示例

| 触发器 | 条件 | 动作 |
|--------|------|------|
| 专利 legal_status 变更为"granted" | 无 | 自动设置 risk_level 为"low" |
| 新专利导入 | applicant 包含"某公司" | 自动关联到对应项目 |
| risk_level 变更为"critical" | 无 | 发送通知 + 标记紧急 |
| filing_date 超过 3 年未授权 | 无 | 自动标记 risk_level 为"high" |
| 专利被标记驳回 | 无 | 自动归档 + 移出活跃视图 |

## 二、数据模型设计

### 2.1 AutomationRule 模型（新增）

```python
class AutomationRule(Base):
    __tablename__ = "automation_rules"
    id = Column(Integer, primary_key=True, index=True)
    database_id = Column(Integer, ForeignKey("patent_databases.id"), nullable=False, index=True)
    name = Column(String(200), nullable=False)
    description = Column(Text)
    is_enabled = Column(Boolean, default=True)
    priority = Column(Integer, default=0)  # 执行优先级（数字越小越先执行）

    trigger_config = Column(JSON, nullable=False)
    # trigger_config 结构:
    # {
    #   "type": "field_changed" | "record_created" | "record_imported" | "schedule" | "manual",
    #   "field": "legal_status",       # field_changed 时指定
    #   "schedule": "0 9 * * *",       # schedule 类型的 cron 表达式
    # }

    condition_config = Column(JSON, default=list)
    # condition_config 结构: 条件数组，全部满足才执行
    # [
    #   {"field": "applicant", "op": "contains", "value": "某公司"},
    #   {"field": "legal_status", "op": "==", "value": "pending"}
    # ]

    action_config = Column(JSON, nullable=False)
    # action_config 结构: 动作数组，按顺序执行
    # [
    #   {"type": "set_field", "field": "risk_level", "value": "low"},
    #   {"type": "link_to_project", "project_id": 5},
    #   {"type": "send_notification", "channel": "in_app", "message": "..."},
    #   {"type": "add_tag", "tag": "auto_tracked"}
    # ]

    last_executed_at = Column(DateTime, nullable=True)
    execution_count = Column(Integer, default=0)
    failure_count = Column(Integer, default=0)
    created_at = Column(DateTime, server_default=func.now())
    updated_at = Column(DateTime, server_default=func.now(), onupdate=func.now())
```

### 2.2 AutomationLog 模型（新增）

```python
class AutomationLog(Base):
    __tablename__ = "automation_logs"
    id = Column(Integer, primary_key=True, index=True)
    rule_id = Column(Integer, ForeignKey("automation_rules.id"), nullable=False, index=True)
    patent_id = Column(Integer, ForeignKey("patents.id"), nullable=True, index=True)
    trigger_type = Column(String(50))
    status = Column(String(20))  # success / failed / skipped
    error_message = Column(Text, nullable=True)
    executed_at = Column(DateTime, server_default=func.now())
    details = Column(JSON)  # 执行详情
```

## 三、触发器类型

| 类型 | 标识 | 说明 | 参数 |
|------|------|------|------|
| 字段变更 | field_changed | 指定字段值发生变化时触发 | field |
| 记录创建 | record_created | 新专利创建时触发 | - |
| 记录导入 | record_imported | 批量导入完成时触发 | - |
| 定时触发 | schedule | 按 cron 表达式定时触发 | schedule |
| 手动触发 | manual | 用户手动点击执行 | - |

---

## 四、动作类型

| 类型 | 标识 | 说明 | 参数 |
|------|------|------|------|
| 设置字段 | set_field | 更新指定字段值 | field, value |
| 关联项目 | link_to_project | 关联到指定项目 | project_id |
| 发送通知 | send_notification | 应用内通知 | channel, message |
| 添加标签 | add_tag | 添加标签 | tag |
| 移除标签 | remove_tag | 移除标签 | tag |
| 变更视图 | move_to_view | 加入/移出指定视图 | view_id, action |

### 5.2 定时任务集成

```python
# 使用 APScheduler 实现定时触发
from apscheduler.schedulers.background import BackgroundScheduler

scheduler = BackgroundScheduler()
scheduler.add_job(
    AutomationEngine._execute_schedule,
    trigger="cron",
    minute="*/5",  # 每5分钟扫描一次
    id="automation_schedule"
)
scheduler.start()
```

## 八、集成点

1. `PatentService.update_patent` 末尾调用 `AutomationEngine.on_event("field_changed", ...)`
2. `ImportService` 导入完成后调用 `AutomationEngine.on_event("record_imported", ...)`
3. `PatentService.create_patent` 后调用 `AutomationEngine.on_event("record_created", ...)`
4. APScheduler 后台线程定时扫描 schedule 类型规则
