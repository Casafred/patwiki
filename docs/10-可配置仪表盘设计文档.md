## 一、需求概述

### 1.1 现状分析

PatWiki 当前**无仪表盘/数据概览功能**。用户需要在表格中手动统计，无法直观查看专利组合的整体状态。飞书多维表格提供可配置的数据仪表盘，支持多种图表类型。

### 1.2 目标

- 新增可配置仪表盘功能
- 支持 6+ 图表类型（数值卡/柱状图/饼图/折线图/进度条/表格）
- 支持自由拖拽布局
- 支持按数据库/视图筛选数据源
- 使用 ECharts 渲染图表

### 1.3 专利场景示例

| 图表 | 类型 | 说明 |
|------|------|------|
| 专利总数 | 数值卡 | 显示当前数据库专利总量 |
| 法律状态分布 | 饼图 | 授权/驳回/待审占比 |
| 申请人排行 | 柱状图 | Top 10 申请人专利数 |
| 申请趋势 | 折线图 | 按年/月统计申请量 |
| 风险分布 | 柱状图 | critical/high/medium/low 分布 |
| 授权率 | 进度条 | 已授权/总数百分比 |

## 二、数据模型设计

### 2.1 Dashboard 模型（新增）

```python
class Dashboard(Base):
    __tablename__ = "dashboards"
    id = Column(Integer, primary_key=True, index=True)
    database_id = Column(Integer, ForeignKey("patent_databases.id"), nullable=False, index=True)
    name = Column(String(200), nullable=False)
    description = Column(Text)
    layout = Column(JSON, default=list)
    # layout 结构: 图表卡片布局数组
    # [
    #   {
    #     "id": "card_1",
    #     "type": "metric",
    #     "title": "专利总数",
    #     "config": {"field": "id", "aggregation": "count"},
    #     "position": {"x": 0, "y": 0, "w": 3, "h": 1}
    #   },
    #   {
    #     "id": "card_2",
    #     "type": "pie",
    #     "title": "法律状态分布",
    #     "config": {"field": "legal_status", "aggregation": "count"},
    #     "position": {"x": 3, "y": 0, "w": 5, "h": 2}
    #   }
    # ]
    created_at = Column(DateTime, server_default=func.now())
    updated_at = Column(DateTime, server_default=func.now(), onupdate=func.now())
```

## 三、图表类型

| 类型 | 标识 | 说明 | 配置 |
|------|------|------|------|
| 数值卡 | metric | 单个关键数值 | field, aggregation |
| 柱状图 | bar | 分类统计 | field, aggregation, group_by |
| 饼图 | pie | 占比分布 | field, aggregation |
| 折线图 | line | 时间趋势 | date_field, aggregation, interval |
| 进度条 | progress | 百分比 | field, target_value |
| 数据表 | table | Top N 列表 | field, aggregation, limit |

## 五、API 设计

| 端点 | 方法 | 用途 |
|------|------|------|
| /api/dashboards | GET/POST | 列出/创建仪表盘 |
| /api/dashboards/{id} | GET/PUT/DELETE | 查看/更新/删除仪表盘 |
| /api/dashboards/{id}/data | GET | 获取仪表盘数据 |
| /api/dashboards/{id}/cards | POST | 添加卡片 |
| /api/dashboards/{id}/cards/{card_id} | PUT/DELETE | 更新/删除卡片 |

### 6.2 图表渲染

使用 ECharts 渲染：
```tsx
import ReactECharts from "echarts-for-react";

function BarChartCard({ data }) {
    const option = {
        xAxis: { type: "category", data: data.labels },
        yAxis: { type: "value" },
        series: [{ type: "bar", data: data.values }]
    };
    return <ReactECharts option={option} style={{height: 200}} />;
}
```
