## 一、需求概述

### 1.1 现状分析

PatWiki 当前**无评论/协作功能**。专利管理是团队协作场景，需要在专利记录上进行讨论、标注和决策追踪。飞书多维表格支持单元格级评论和记录级讨论。

### 1.2 目标

- 支持记录级评论（对整条专利记录评论）
- 支持字段级评论（对特定字段值评论）
- 支持回复和 @提及
- 支持评论已解决/未解决状态
- 支持评论历史追溯

### 1.3 专利场景示例

| 场景 | 评论类型 | 说明 |
|------|---------|------|
| 风险讨论 | 字段级 | 对 risk_level 字段讨论"为何标记为 critical" |
| 技术评审 | 记录级 | 对整条专利进行技术评审讨论 |
| OA 策略 | 字段级 | 对 legal_status 讨论 OA 答复策略 |
| 任务分配 | 记录级 | @张三 请跟进此专利的年费缴纳 |

## 二、数据模型设计

### 2.1 Comment 模型（新增）

```python
class Comment(Base):
    __tablename__ = "comments"
    id = Column(Integer, primary_key=True, index=True)
    database_id = Column(Integer, ForeignKey("patent_databases.id"), nullable=False, index=True)
    patent_id = Column(Integer, ForeignKey("patents.id"), nullable=False, index=True)
    
    # 评论类型：record=记录级, field=字段级
    comment_type = Column(String(20), default="record")  # record / field
    # 字段级评论时指定字段 key
    field_key = Column(String(100), nullable=True, index=True)
    
    # 评论内容
    content = Column(Text, nullable=False)
    # 支持富文本和 @提及
    # @提及格式: @[用户名](user:123)
    
    # 回复关系
    parent_id = Column(Integer, ForeignKey("comments.id"), nullable=True, index=True)
    
    # 状态
    is_resolved = Column(Boolean, default=False)  # 是否已解决
    resolved_by = Column(String(100), nullable=True)
    resolved_at = Column(DateTime, nullable=True)
    
    # 作者
    author_id = Column(String(100), nullable=False)
    author_name = Column(String(100), nullable=False)
    
    # 提及的用户列表
    mentions = Column(JSON, default=list)  # ["user:123", "user:456"]
    
    created_at = Column(DateTime, server_default=func.now())
    updated_at = Column(DateTime, server_default=func.now(), onupdate=func.now())
```

### 3.2 @提及解析

```python
import re

MENTION_PATTERN = re.compile(r'@\[([^\]]+)\]\(user:([^)]+)\)')

def parse_mentions(content: str) -> list:
    # 从评论内容中提取 @提及的用户
    matches = MENTION_PATTERN.findall(content)
    return [{"name": name, "user_id": uid} for name, uid in matches]

def render_mention(content: str) -> str:
    # 将 @提及渲染为 HTML（前端展示用）
    return MENTION_PATTERN.sub(
        r'<span class="mention" data-user-id="\2">@\1</span>',
        content
    )
```

## 四、API 设计

| 端点 | 方法 | 用途 |
|------|------|------|
| /api/comments | POST | 创建评论 |
| /api/comments/patent/{patent_id} | GET | 获取专利评论列表 |
| /api/comments/{id} | PUT/DELETE | 更新/删除评论 |
| /api/comments/{id}/resolve | POST | 标记已解决 |
| /api/comments/{id}/unresolve | POST | 重新打开 |
| /api/comments/{id}/reactions | POST | 添加表情反应 |
| /api/comments/unresolved/{patent_id} | GET | 获取未解决数 |
