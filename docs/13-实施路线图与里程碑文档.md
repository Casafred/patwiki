## 五、技术选型决策记录（ADR）

| ADR | 决策 | 理由 |
|-----|------|------|
| ADR-001 | 公式引擎用 Python ast 模块 | 安全可控，无需引入第三方解析器 |
| ADR-002 | 通用 CrossTableLink 模型 | 避免为每种关联硬编码模型 |
| ADR-003 | 视图类型用 String 而非 Enum | 便于扩展，无需数据库迁移 |
| ADR-004 | 导出用 pandas + openpyxl | 成熟稳定，格式控制能力强 |
| ADR-005 | 仪表盘用 ECharts | 功能丰富，中文文档好 |
| ADR-006 | 自动化用 APScheduler | 轻量级，适合本地桌面应用 |
| ADR-007 | 拖拽用 @dnd-kit | 现代 React 拖拽库，支持虚拟化 |
| ADR-008 | 布局用 react-grid-layout | 可拖拽网格布局标准方案 |

## 六、PatWiki 独有优势保留清单

在升级过程中，必须保留 PatWiki 相比飞书多维表格的 6 项独有优势：

| 优势 | 说明 | 保护措施 |
|------|------|---------|
| Wiki 式增量合并 | 专利数据增量合并而非覆盖 | 不修改 ImportService 的合并逻辑 |
| 同族/引用解析 | 自动解析专利同族和引用关系 | 不影响 PatentFamily 模型 |
| AI 批量抽取 | AI 批量抽取专利字段 | 保留 AI_FIELD 类型 |
| 法律状态建模 | 法律状态的结构化建模 | 不修改 LegalStatus 模型 |
| 本地优先 | 数据存储在本地 SQLite | 不引入云端依赖 |
| 同族聚拢 | 同族专利自动聚拢展示 | 保留同族视图逻辑 |

## 七、风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| 公式引擎性能瓶颈 | 中 | 高 | 增量更新 + 批量计算 + 缓存 |
| 拖拽性能（大量卡片） | 中 | 中 | 虚拟滚动 + 分页加载 |
| SQLite 并发限制 | 低 | 中 | 读写分离 + WAL 模式 |
| 前端包体积膨胀 | 中 | 低 | 按需加载 + 代码分割 |
| 向后兼容性破坏 | 低 | 高 | 迁移脚本 + 回归测试 |
