# 统一 Wiki、字段版本与导入升级

## 数据规则

1. `Patent` 是全局唯一的专利 Wiki，申请号、公开号和授权号通过 `PatentIdentifier` 统一定位。多个号码命中不同专利时继续隔离，禁止根据同族关系合并身份。
2. 默认主表展示全部有效 Wiki。其他库通过 `PatentDatabaseMembership` 记录入口，视图保留筛选、列配置和成员关系。
3. 任意库编辑共享字段均修改同一个 Wiki。视图扩展列提升为全局人工字段，原本地列成为显示别名。旧值和来源视图保存在历史中。
4. 协同包的人工字段也参与统一 Wiki 的三方冲突审查。未解决冲突保留当前值；明确决策后修改全局记录。历史库内基线作为来源证据保留。

## 现有问题与修正

| 问题 | 原因 | 修正 |
| --- | --- | --- |
| 导入字段选择混乱 | 用 SQL 存储位置区分系统与自定义，且下拉菜单排除了当前自定义选项 | 按业务分组列出统一字段；人工/系统、固定/可变独立显示 |
| 自定义列难以归并 | AI 的目标映射配置不能完成已有数据治理 | 新增归并预览和执行，支持保留、采用新版本、文本/集合融合，停用来源字段并更新映射模板与视图别名 |
| 新值导入后不显示 | 内容差异默认保留旧值 | 常规字段默认采用新版本，旧值保存在历史，原始来源继续保留 |
| 导入中断丢失映射 | 临时文件存在，但会话元数据及界面选择未持久化 | 每个库保存源文件、工作表、映射和选项；后端重启后仍可恢复 |
| 修改映射后预审失败无法重试 | 确认接口在失败路径也会删除临时文件 | 使用持久源文件恢复；新预审成功后才废止原待审批次 |
| 主表看不到其他库导入 | 批次查询始终只过滤当前库 | 默认主表查询全局批次，界面提供同步记录筛选和来源库 |
| 同族错误长期保留 | 重建把旧自动 family_id 当作证据；拆分组件可能重复复用一个族；查询按旧 owner 判断跨库并重复列出成员 | 自动族按明确来源号码重建，复用族只能用于一个组件；严格匹配，按成员可见范围去重 |
| 同族关系跨库变化 | 重建只处理一部分库中的全局记录 | 全局重建，不制造关系占位专利；导入关系后重新计算投影 |

## 字段属性和冲突规则

字段元数据新增 `value_source`、`value_stability`、`merge_policy`、`validation_rules` 和 `versioned`。

| 示例 | 来源 | 稳定性 | 默认导入规则 |
| --- | --- | --- | --- |
| 申请号、公开号、授权号、国别 | 系统 | 固定 | 保留当前身份，额外号码继续作为身份事实保存 |
| 日期、专利类型、IPC、摘要 | 系统 | 固定 | 新版本，保留旧值；可调整为保留或隔离差异 |
| 法律状态、权利要求、专利权人 | 系统 | 可变 | 新版本，保留旧值 |
| 技术问题、技术方案、技术效果、备注、自定义字段 | 人工 | 可变 | 新版本，保留旧值 |
| 图片、附件、关联、公式 | 依实际类型 | 依实际类型 | 沿用专门存储及处理，不使用文本版本编辑 |

“固定”表示通常不会随时间改变，不等于拒绝来源纠错。身份字段禁止设置自动覆盖不同号码。必填、长度、数值范围规则在录入和导入路径使用；导入规则以预审时的快照为准。

## 字段版本

Wiki 新增“字段版本”页：选择字段后展示当前值、完整演变记录与文件/同步来源候选。编辑、选用历史值、回退或融合后保存为新的版本。旧版本不会删除。

当前值仍保存在原有列中，维持搜索、排序、筛选和导出的兼容性。版本保存在 `PatentHistory`，导入候选保存在 `FieldObservation` 和 `ImportFieldGovernanceAudit`。日期、数字、枚举也保留多个历史版本，当前投影仍有明确类型。

版本编辑带当前值检查，页面打开后其他流程修改了同一字段时，阻止过期页面覆盖。此前已经丢失、从未记录的旧值无法重建。

## 导入恢复和审查

- 未完成导入可以从新建导入窗口恢复到字段映射。
- 已有待审批次可从导入历史“返回字段映射”，包括升级前保留原始文件的历史批次。
- 映射调整后重新预审，原待审批次标记为被新批次替代，不写入两次专利数据。
- 审查提供全部单元格、全部差异、仅新旧值冲突三个范围；切换范围和翻页前保存决策。
- 空导入值不自动清空已有值。审查后发生并发变动仍隔离来源值。
- 审查窗口最大宽度提升到 1500px；手机使用窗口内部横向滚动检查各列。

## 升级与验证

启动时运行幂等数据升级：先用 SQLite backup 生成一致性备份，再迁移旧视图字段、保留旧协同库字段证据、重建自动同族投影，最后保存升级标记。原始库内值未删除。备份路径保存在升级标记中。

新增专项测试覆盖跨库导入只保留一个 Wiki、字段默认新版本、策略校验、历史回退、过期编辑阻止、误同族拆分、跨库同族显示、视图字段全局读取、自定义字段归并、重启后的映射恢复与失败重试。现有导入、身份、协同、外部同步及迁移测试一起验证。
