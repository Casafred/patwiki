# 成员初始化配置

格式样例位于 `frontend/public/examples/patwiki-employee-config.example.json`，也可在协作与权限页面下载。

样例中的哈希、公钥和签名是占位符，仅用于了解结构，不能直接导入。正式配置由管理员在「协作与权限 → 成员权限配置」中选择账号和部门代号后下载，无需手工编写。账号需先设置工号、协同登录名及密码。

文件顶层包含 `payload` 和 `signature`。`payload` 中的字段必须完整且不能添加额外字段：

| 字段 | 格式 |
| --- | --- |
| format / version | 固定为 `patwiki.employee-config` / `1` |
| department_code | 部门代号，1 至 80 字符 |
| employee_no | 工号，1 至 50 字符 |
| user_uid | `user_` 加 32 位小写十六进制字符 |
| username | 小写字母、数字以及 `_ . @ -`，1 至 100 字符 |
| display_name | 显示名，1 至 100 字符 |
| role | `system_admin`、`member` 或 `viewer` |
| active | JSON 布尔值 |
| password_hash | 系统生成的 Argon2 密码哈希，不是明文密码 |
| issued_at | UTC 时间，不带时区后缀，如 `2026-10-04T00:00:00` |
| issuer_public_key | Base64 编码的 Ed25519 公钥 |
| database_permissions | 库权限数组，可为空 |

每条库权限包含 `database_uid`（`db_` 加 32 位小写十六进制字符）、`actions`（`export` 和 / 或 `apply`）及 `fields`（字段名数组）。

`signature` 由管理员的签名密钥生成，覆盖完整 `payload`。编辑其中任何值后都需要重新签发；在初始化后的客户端，仅能导入同一成员、同一签发者的更新文件。
